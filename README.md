# StudySprint

A zero budget student study web app focused on fast revision and active recall.

## Features

• Paste or import study material
• Build a local study pack
• Generate revision topics and flashcards
• Generate quick recall questions
• 10, 20, 30 and 60 minute study sprints
• Local progress tracking
• Weak area tracking
• Responsive dark interface
• No account or backend required for the MVP

## Stack

HTML, CSS and JavaScript.

The MVP stores data in browser LocalStorage. GitHub Pages works as the deployment target.

## Run locally

Open `index.html` in a browser.

## Project goal

StudySprint focuses on a practical student problem: turning a large amount of study material into a short, structured revision session.
